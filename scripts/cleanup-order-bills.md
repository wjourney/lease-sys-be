# 历史误重建账单清理

先部署修复后的订单编辑逻辑，再在服务器应用目录使用服务器现有的数据库环境执行。不要连接或创建本地数据库。

```sh
node dist/cli/cleanup-order-bills.js
```

默认只读，输出候选账单及对应有效账单。只识别最后一次操作为“修改租约，重建未收款账单”、订单操作日志证明没有计费字段变化、有效账单业务字段完全相同、且旧账单不存在任何收付款/发票/材料引用的记录。不处理真正因计费变更作废的账单，不处理佣金作废记录，也不推测缺失的佣金金额。

确认输出范围后执行（管理员 UUID 使用现有管理员，备份路径必须为新的绝对路径）：

```sh
node dist/cli/cleanup-order-bills.js --apply --actor-id ADMIN_UUID --backup /absolute/private/backup-order-bills.json
```

执行前生成权限为 0600 的备份；事务内锁定订单和账单，再次校验版本和所有引用。有并发变化则整批回滚。仅设置旧记录 deletedAt/deletedBy，并追加审计日志，不物理删除、不变更有效账单、不改变已收款金额。重新执行时已归档记录不再入选。备份包含业务资料，应保存在受限目录。

若需要撤销，应依据备份逐条核查归档后是否发生新业务，再通过带版本校验的维护事务恢复 deletedAt/deletedBy；不要直接覆盖整张表或覆盖新的操作记录。
