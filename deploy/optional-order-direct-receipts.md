# 订单简化与直接收款发布说明

前后端必须配套部署。先执行数据库迁移、更新后端，再发布前端。本次未在本地创建数据库，也未执行服务器数据迁移。

## 数据迁移

执行标准 `prisma migrate deploy`，包括尚未发布的单位类型/整期账单迁移，以及 `20261007180000_optional_order_direct_receipts`。新增可空的项目、单位、销售、租金和押金列，新增佣金草稿 JSON。历史应收 `PARTIAL` 状态转换为 `OPEN`，金额和收款记录不变。

历史待核对收款不得自动改为已确认；可从订单或账单的收款记录中按原流程核实、驳回。新收款直接以 CONFIRMED 写入，同时更新收据、应收余额和订单首期状态；资金流水由确认收款及冲正记录汇总。

## 默认规则

仅公司/租客名称必填。未选单位或没有有效租金的订单为 DRAFT（待完善），不占用单位、不出账、不生成合同。起租日默认当天，到期日默认一年后前一天，月付、港元、押一付一；有单位时带入参考月租。补齐后按月生成整个租期账单。销售及佣金约定允许后补；佣金方式、金额、日期和销售齐全才生成佣金明细。缺少的字段不应被伪造为零。

首期声明已付款时带入应收金额和当天到账日期，使用唯一有效银行账户；提交直接入账，无需财务再次确认。仍保留金额不超可收余额、有效账户、权限、订单占用及重复提交保护。部分到账的账单仍为 OPEN；应收仅有 OPEN/PAID/VOID 三种状态。

## 批量操作

订单列表无批量操作，保留单笔操作。账单支持所选导出、批量登记收款和批量下载发票 ZIP（最多 20 笔账单、100 张发票、合计 50 MB），下载结果清单列明无发票或失败项；只下载已确认收款对应的有效发票。佣金管理支持所选导出、批量登记付款，复用单笔付款接口的权限、余额、幂等和流水处理。

账单批量收款逐笔独立事务和提交标识，可填写各笔金额，共用日期/账户/支付方式/凭证。重试不重复入账；凭证失败不回滚已经成功的收款，可在收款记录补传。销售角色没有批量写权限。

## 校验

前端 Vitest、类型检查、构建以及模拟全部 API 的 Playwright 测试；后端类型检查、编译和无数据库单元回归。服务器上线后需验证迁移成功，再用经授权的业务测试数据验证录单、收款与流水。
