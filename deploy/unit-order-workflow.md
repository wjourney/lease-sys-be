# 单位类型与整期账单升级

先部署数据库迁移及后端，再部署前端。新增 billingVersion 默认 1 保留历史计算；新订单写入 2 使用起租日锚定的月账期。

在服务器应用环境运行（本地不建数据库）：

```
node dist/cli/backfill-unit-order-workflow.js
node dist/cli/backfill-unit-order-workflow.js --apply
```

第一条仅检查并输出计划，不修改数据。核对 incomplete 类型后再应用；脚本不会编造缺失楼层、面积、楼龄，需要在项目页面补全这些类型后才能用于新建单位。

旧单位按自身实际属性拆分类型，保持房号、实际价格和订单快照不变。补账只处理未结束订单、保持历史算法，仅插入缺失账期及月结佣金。一次性佣金不扩展。已生成、已确认、已作废记录不覆盖。重复运行不会重复插入账单或佣金。

应用前保留数据库备份；不要对完成/关闭订单批量生成新应收。
